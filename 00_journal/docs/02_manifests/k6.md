# Documentation to the k6 manifest

1. `annotations:` / `proxy.istio.io/config:` - this section overwrites the config of the sidecar (Envoy) for this pod
   - Sources:
     - https://istio.io/latest/docs/reference/config/annotations/
2. `proxyStatsMatcher` with `inclusionRegexps` - says which metrics Envoy should export to Prometheus
   - Sources:
     - https://www.envoyproxy.io/docs/envoy/latest/configuration/listeners/stats
3. `net.ipv4.ip_local_port_range: "1024 65535"` - a wider range of local ports to use for outgoing connections
   - Sources:
     - https://kubernetes.io/docs/tasks/administer-cluster/sysctl-cluster/
4. `net.ipv4.tcp_tw_reuse: "1"` - allows reusing ports that are in TIME_WAIT state. This sysctl is not in the Kubernetes safe list, so it is enabled with `--kubelet-arg-allowed-unsafe-sysctls` in `setup_cluster.sh`
   - Sources:
     - https://www.kernel.org/doc/html/latest/networking/ip-sysctl.html
